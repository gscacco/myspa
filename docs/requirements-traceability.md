## Security and regression emphasis

- `LT-003`, `LT-017`, and `LT-025` are import and DOM-injection gates. Include hostile strings containing closing tags, unsafe schemes, event attributes, unsupported EDN forms, and malformed Hiccup.
- `LT-013`, `LT-018`, `LT-019`, and `LT-020` cover the code trust and reevaluation boundary, including observed evaluation counts and local error recovery.
- `LT-021R` and `LT-026` protect Foglio and Timetable when shared modules move. Keep their existing tests at their current import paths.
- `LT-001` tests the built artifact, not merely source modules. `LM-001` and `LM-002` are needed because JSDOM cannot establish real layout or assistive-technology usability.

## Planned execution gates

Targeted test commands are `node --import ./tools/load-scittle.js --test tests/loom/<feature>.test.js` where SCI is needed, and `node --test tests/loom/<feature>.test.js` otherwise. The full gate is `npm run check`; separate artifact gates are `npm run build:timetable`, `npm run test:e2e:timetable`, and `npm run build:loom`. `npm run test:loom` runs implemented Loom tests. `npm run test:timetable` includes synthetic OFD cases but excludes the ten tests requiring the external `OR_30_SETT.ofd` fixture. Run those explicitly with `npm run test:integration:ofd` when the fixture is present. Further feature tests and manual gates remain planned.

Before each implementation commit or merge, inspect `git status`, review the relevant diff, and record the actual targeted and full-gate results.

Hiccup `style` and `key` support was added with tests first. The rendering tests failed because both attributes were rejected. Existing-tag completion was added with tests first. The new tag tests failed because the Tags field had no suggestion popup. The field now reads unique tag names from the current item store, opens a contextual list on focus or input, groups prefix matches first, filters case-insensitively, excludes tags already entered, and commits mouse, Enter, or Tab selections without touching other tokens. Escape dismisses the list without changing the field. Canonical wiki-style transclusion was added with tests first. The new rendering tests failed because `![[item:uuid]]` had no parser token and the transclusion surface still used the old left-border style. The Markdown parser now recognizes standalone occurrences as a block token and occurrences inside ordinary text as an inline token, with optional `#heading-slug` section targets. Both paths reuse the existing source-ID, navigation, cycle, depth, and dependency logic. The embed container now shares the executable output surface's border, background, radius, spacing, and margin. A follow-up regression showed that `\![[item:uuid]]` leaked an exclamation mark plus an item link; escaped transclusions now render as inert literal text. Code and malformed syntax remain inert, missing targets fail locally, and the app refreshes the embed after source edits without opening the source automatically. `npm run test:loom` passed 27/27 files and `npm run build:loom` wrote a 1,086,302-byte artifact on 2026-10-25.
