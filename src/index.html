The panel above contains user-defined ClojureScript functions. Names declared
with def/defn are available in cell formulas.

Spreadsheet formulas: =B2*C2   =D6>1000?"High":"Low"
A1  $A$1  Sheet2!B3 → cell value
A1:B5 → a matrix (vector of rows); use (flatten …) to flatten it
In ternary expressions, put spaces around «:» → =x ? B2 : C2 (B2:C2 without spaces is a range)
SUM AVG MIN MAX COUNT ROUND IF and math functions (sqrt, abs, PI…) are also available in ClojureScript.

In the floating editor, enter the ClojureScript form without a leading =:
(double-value B2)     (SUM A1:B5)     (if (> D6 1000) "High" "Low")

The ClojureScript editor has paredit:
( ) [ ] { } and " close automatically · Enter adds an indented line · Tab indents (Shift+Tab outdents)
Paredit keeps delimiters balanced. Backspace/Delete cannot unbalance them, while a whole form or block can be deleted.
Use the paredit buttons or shortcuts on the list containing the cursor, including when the cursor is just after its closing «)»:
  Slurp ➡  pull the following form into the list             Ctrl+→
  ⬅ Barf   push the last form out of the list                Ctrl+←
  Splice ⬆ remove the list's delimiters                      Ctrl+↑
  Wrap ⬇   wrap the form or selection in «( )»               Ctrl+↓
  (On macOS, if Mission Control captures Ctrl+arrows, use Ctrl+Shift+arrows.)
Ctrl+/ comments a line with ; · Ctrl+Space opens suggestions
▶ Apply all evaluates the editor and saves its code in the workbook.
▶ Evaluate form (Ctrl+Enter) evaluates only the s-expression before the cursor, like Emacs C-x C-e.
It can redefine a function or constant without reloading the rest of the editor. The change lasts for this session; use Apply all to save it.

Example:
(defn weighted-average [values weights]
  (let [value-list (flatten values)
        weight-list (flatten weights)]
    (/ (SUM (map * value-list weight-list)) (SUM weight-list))))
Use it in a cell as (weighted-average B2:B5 C2:C5).
Conditionals: (if (> D6 1000) "High" "Low") · Locals: (let [x 1] (* x 2))
Data flow: a cell recalculates only when one of its dependencies changes.
