Il pannello qui sopra contiene le funzioni utente in ClojureScript: i simboli definiti
con def/defn diventano disponibili nelle formule delle celle.

Le formule restano espressioni del foglio: =B2*C2   =D6>1000?"Alta":"Bassa"
A1  $A$1  Foglio2!B3 → valore di una cella
A1:B5 → matrice (vettore di righe) da appiattire con (flatten …)
Nei ternari metti spazi attorno a «:»  →  =x ? B2 : C2  (B2:C2 senza spazi è un intervallo)
SUM AVG MIN MAX COUNT ROUND IF + funzioni matematiche (sqrt, abs, PI…) usabili anche nei cljs

Editor con paredit attivo:
( ) [ ] { } e " si chiudono da soli · Invio rientra · Tab indenta (Shift+Tab toglie)
Le parentesi non si possono sbilanciare: se una cancellazione (Backspace/Delete) le
romperebbe paredit la blocca, mentre una forma o un blocco interi si cancellano.
Per cambiarle usa i pulsanti paredit o i tasti, che agiscono sulla lista in cui si
trova il cursore (anche se il cursore è subito dopo la sua «)»):
  Slurp ➡  tira dentro la lista la forma che segue      Ctrl+→
  ⬅ Barf   spinge fuori dalla lista l'ultima forma      Ctrl+←
  Splice ⬆ toglie le parentesi della lista              Ctrl+↑
  Wrap ⬇   avvolge la forma o la selezione in «( )»     Ctrl+↓
  (su macOS, se Ctrl+frecce è preso da Mission Control, usa Ctrl+Shift+frecce)
Ctrl+/ commenta (;) · Ctrl+Spazio suggerimenti
▶ Applica tutto valuta l'editor e ne salva il codice nel foglio (anche nel file salvato)
▶ Valuta forma (Ctrl+Invio) valuta solo la s-exp prima del cursore, come C-x C-e di
Emacs: ridefinisce una defn o una costante def senza ricaricare il resto e senza
salvarla nel foglio (vale per la sessione; per conservarla usa ▶ Applica tutto).
Esempio: (defn media [xs] (/ (SUM xs) (count xs)))   poi in una cella  =media(B2:B5)
condizionali: (if (> D6 1000) "Alta" "Bassa")   locali: (let [x 1] (* x 2))
Data flow: una cella si ricalcola solo se cambia una cella da cui dipende (le dipendenze sono scoperte durante il calcolo).
